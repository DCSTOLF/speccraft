# Domain: spec-lifecycle

Spec lifecycle commands and their gating: `spec:revise` status gates, artifact archival, `revision:` counter, spec-reviser subagent, code cross-check.

- `/speccraft:spec:revise` operates on the active spec only, gated to source status `draft|reviewed|planned` (rejecting `in-progress`/`closed`/`archived` with a status-naming error) and errors when `active_spec` is empty (spec 0015)
- On a real spec.md edit, revise increments the `revision: N` frontmatter counter (inserting `revision: 0` if absent — command-owned, never agent-owned), archives stale downstream artifacts by renaming `review.md`/`plan.md`/`tasks.md` to `*-r<N_old>.md` per source status, and resets status to `draft`; a whitespace/newline-only edit is a no-op that changes nothing and prints `no changes — spec unchanged` (spec 0015)
- Revise's optional code cross-check greps identifier tokens found in backtick spans (regex `[A-Za-z_][A-Za-z0-9_]{3,}`) within `## What`/`## Acceptance criteria`/`## Out of scope` across `packages[]` using portable `find`/`grep` (never ripgrep); zero-match tokens become `^Q-DRIFT:`-prefixed re-interview questions, and an empty `packages[]` prints `packages[] empty — skipping code cross-check` and proceeds (spec 0015)
- The `spec-reviser` subagent (`tools: [Read, Write, Edit, Bash]`, no `Agent` tool) re-runs the Socratic interview against existing spec.md content and must not modify the command-owned frontmatter keys `revision:`/`status:`/`id:`/`created:` (spec 0015)
- Revise preflights before any mutation: it aborts (modifying nothing, not invoking the reviser) when a required source artifact for the source status is missing — the old `*-r<N>.md` archive-collision refusal (`preflight_archive_collisions`) is removed in favor of spec 0036's self-healing ordinal selection (spec 0015)
- Planning/execution authoring prose (`tdd-planner.md`, `spec:{plan,implement,delegate}.md`) and the shipped `templates/speccraft/conventions.md` are stack-agnostic: they reference the project's `speccraft-state test-command` / conventions.md value rather than Go idioms, with a concrete language test command allowed only under a labeled `Example`; two meta-tests enforce both the prose rule and the template's freedom from language-specific `enforce:` regexes and idioms (`fmt.Errorf`, `slog`, `*_test.go`) (spec 0034)
- `/speccraft:spec:review --diff` runs a diff-focused re-review: `speccraft-state review-snapshot write` freezes `spec.md`, and `review-diff [--promote]` emits a versioned JSON envelope (`snapshot`/`changed`/`changed_sections`/`diff`/`fingerprint`/`base_fingerprint`) from a section-anchored textual diff keyed by `##` heading + ordinal (byte-identical bodies never reported) (spec 0035)
- The command classifies via a provenance gate on the prior `review.md`'s `reviewed_sha256` vs the envelope `base_fingerprint`: byte-identical → short-circuit (no reviewers); baseline-not-last-reviewed or first review → full review with a warning; else scoped re-review of the changed sections plus a regression sweep over previously-approved criteria (`templates/prompts/re-review.md`) (spec 0035)
- `review.md` records the reviewed `spec.md` fingerprint (sha256 of raw bytes) as one `reviewed_sha256:` line via a single atomic temp-then-rename commit written only after the review workflow completes (verdict-independent; nothing written on any failure); `review-snapshot.md` persists under `specs/`, outside the `speccraft-drift` scan scope (spec 0035)
- The revision counter and archived `*-r<N>.md` artifacts are reconciled by one authority model: `Effective = hasArchived ? max(fmRev, maxArchived+1) : fmRev` (frontmatter `revision:` is canonical; archives only heal it forward, never backward), surfaced by `ComputeRevisionState`, `speccraft-state effective-revision`, and the heal-only `reconcile-revision` (a no-op when the counter already leads) (spec 0036)
- Revise archiving is self-healing and no-clobber: it moves each disposable live artifact (`review.md`, plus `plan.md`/`tasks.md` for `planned` source) to `*-r<A>.md` at ordinal `A = Effective` (provably free) via a genuine no-replace primitive (`link(2)`-then-unlink, failing safe where unavailable, idempotent by inode identity across an interrupted move), never archives `spec.md`, then writes the counter to post-archive `Effective` and flips `status` to `draft` last — so a pre-existing `review-r<N>.md` can no longer deadlock revise (spec 0036)
- In-place draft edits intentionally keep the same `revision:` — a revision corresponds to a completed review cycle (an archive), not every edit — so the review→edit→re-review loop within one draft does not advance the counter (spec 0036)
